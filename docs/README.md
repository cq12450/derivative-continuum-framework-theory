
衍生连续：从事件到波函数的推导（草案）

标准量子力学把连续波函数当作基本实体，把离散测量结果当作需要解释的问题。衍生连续把这个顺序颠倒过来：离散事件和它们之间的关联幅才是基本的，连续的波函数是从中衍生出来的。

核心结论：

薛定谔方程是从事件演化推导出来的，不是假设的。

玻恩规则是再生核内积的自然结果，不需要额外公理。

爱因斯坦场方程是事件关系自洽性的体现。

双缝干涉实验存在微小修正，可以被下一代实验检验。

一、问题的起点

量子力学有一个百年悬案：为什么波函数是连续的、确定的，但测量结果是离散的、随机的？

主流的回答有三种：

哥本哈根诠释：就是这样，别问了。

多世界诠释：测量结果不随机，只是世界分裂了。

玻姆诠释：波函数是真实的，粒子是真实的，但存在非定域的量子势。

这三种诠释都把连续波函数当作基本实体，然后想办法解释离散测量。

衍生连续走的是相反的路：如果离散事件才是基本的呢？

二、核心思想

想象你有一张照片，像素很低，你能看到一个个离散的像素点。当你把像素点无限加密，照片就变成了连续的图像。

衍生连续的想法与此类似：

物理世界底层是离散的事件，它们之间有关联。当我们从足够远的距离看，这些离散事件看起来就像一个连续的场。这个“看起来连续的场”就是波函数。

波函数不是基本实体，它是事件关系的衍生品。
